Preguntas frecuentes

Guías para las tareas más comunes.

¿Cómo creo un evento?

Abre “Crear evento” y guarda nombre, descripción, fechas, capacidad, precio y ciudad. Esos datos quedan almacenados en la base de datos.

¿Dónde consulto las reservas?

En “Reservas” verás los registros asociados a tus eventos y el estado almacenado para cada reserva. El sistema no registra pagos.

¿Cómo valido la entrada de un asistente?

El esquema actual no tiene entradas digitales ni check-ins; la vista de asistentes muestra la información de cada reserva.

¿Puedo editar un evento publicado?

El esquema y la API actuales permiten crear y consultar eventos; todavía no permiten editarlos ni eliminarlos.
