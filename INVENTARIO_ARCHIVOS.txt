EVENTSTAGE - INVENTARIO DE ARCHIVOS
===================================

Este inventario describe los archivos versionados relevantes del proyecto.
Las rutas de frontend/src son el codigo fuente del sitio. Las rutas equivalentes
en public se regeneran con "npm run build" y no se deben editar directamente.

RAIZ DEL PROYECTO
-----------------
.env.example — Variables de entorno de ejemplo para Neon, sesiones y servidor.
.gitattributes — Reglas de Git para normalizar archivos de texto.
.gitignore — Archivos locales y secretos que Git debe ignorar.
desktop.ini — Metadatos de visualizacion de carpetas de Windows.
README.md — Instrucciones para Neon, ejecucion local, Vercel e integraciones.
index.js — Entrada de Express para Vercel; dirige la raiz al sitio y monta la API.
package.json — Dependencias, comandos de inicio, compilacion y pruebas.
package-lock.json — Versiones exactas de dependencias de npm.
vercel.json — Configuracion declarativa de Vercel.
scripts\build-frontend.js — Copia frontend/src a public para el despliegue.
INVENTARIO_ARCHIVOS.txt — Este resumen de archivos del proyecto.

BACKEND
-------
backend\src\db.js — Pool de PostgreSQL para Neon y validacion de DATABASE_URL.
backend\src\server.js — API Express: autenticacion, sesiones, ubicaciones,
  eventos, compra simulada, entradas y consultas protegidas por rol.
backend\src\.gitkeep — Conserva el directorio backend/src en Git.
backend\src\controllers\.gitkeep — Conserva el directorio de controladores.
backend\src\models\.gitkeep — Conserva el directorio de modelos.
backend\src\routes\.gitkeep — Conserva el directorio de rutas.

BASE DE DATOS
-------------
database\.gitkeep — Conserva el directorio de scripts de base de datos.
database\migrations\001_add_password_hash.sql — Agrega el hash de contrasena
  requerido por el inicio de sesion.
database\migrations\002_seed_colombia_locations.sql — Inserta Colombia y
  ubicaciones iniciales si aun no existen.
database\migrations\003_create_sessions.sql — Crea la tabla e indices de sesiones.

FRONTEND - BASE Y COMPONENTES
-----------------------------
frontend\src\api.js — Cliente HTTP para la API y selectores de ubicacion.
frontend\src\index.html — Redireccion a la portada de EventStage.
frontend\src\components\.gitkeep — Conserva el directorio de componentes.
frontend\src\components\cambiar-cuenta.css — Estilos del menu movil y boton
  para volver a la portada desde los paneles.
frontend\src\components\cambiar-cuenta.js — Menu movil y navegacion de regreso
  a la pagina principal.
frontend\src\components\role-guard.js — Verifica el rol requerido y dirige a
  iniciar sesion cuando no existe una sesion valida.
